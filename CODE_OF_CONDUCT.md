# Code of Conduct

This project aims to be calm, respectful, and constructive.

Participants are expected to:

- Assume good intent while still being direct about bugs, risks, and design
  disagreements.
- Focus criticism on code, decisions, and evidence rather than on people.
- Avoid harassment, discrimination, intimidation, doxxing, or sustained
  disruptive behavior.
- Respect security and privacy boundaries, especially around unreleased
  hardware, firmware artifacts, credentials, and coordinated disclosure work.

Maintainers may remove comments, patches, or access that undermine a safe and
productive working environment.

## Reporting

Send conduct concerns privately to the Foxie Products maintainers at
[support@foxieproducts.com](mailto:support@foxieproducts.com). Use “Litch conduct”
in the subject. Describe what happened and include a link to the relevant
interaction if one is available.
