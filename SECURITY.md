# Security policy

Report a suspected vulnerability privately to the Foxie Products maintainers at
[support@foxieproducts.com](mailto:support@foxieproducts.com). Use “Litch security”
in the subject so we can route it to the right person.

Include the affected app or firmware version, board revision if relevant, the
impact you observed and enough detail to help us investigate. Please leave
passwords, private keys and other people's personal data out of your report.
Keep sensitive details out of public issues and pull requests.
