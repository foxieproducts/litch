# Hardware revisions

The V3.3 and V3.31 launch boards use the ESP32-S3 V3.3 firmware profile. V3.31 fits R3 and R4 and leaves R5 unpopulated. This gives raw strap value 3 and firmware revision ID 4. See the [revision table](../hardware/hardware_overview.md#target-variants) for the earlier supported profiles.

Use the [pin map](../hardware/pin_map.md), [control map](../hardware/controls.md), [LED topology](../hardware/led_topology.md), [Hall sensor map](../hardware/sensor_topology.md), [I²C devices](../hardware/bus_devices.md) and [power limits](../hardware/power_constraints.md) when servicing a board. The [V3.31 schematic and BOM](../../pcb/README.md) identify the physical components.
