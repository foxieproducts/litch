# Support reports

**Contact Support** prepares an editable report in your mail app. Describe what happened, review the diagnostic text and attachments, then send the email when you are ready. You can remove any information or close the draft without sending it.

Connecting shows **Contact Support** after three seconds. If the selected
board makes no progress for three seconds, the app retries in the same panel.
Each replacement can finish the phone’s Bluetooth connection procedure.
**Cancel** stops retries and returns to the board list. **Contact Support**
stops retries and opens a report for that board. A live connection can supply
diagnostics while the report is open. Close the report to return to the board list.

Reports can include the app and operating system versions, Bluetooth permission status, recent actions and errors, and board firmware information when available. The [app privacy policy](../../app/assets/privacy/foxie_litch_privacy_policy.md) describes what support receives and how long it is kept. See [Support](../../SUPPORT.md) for the contact address.
